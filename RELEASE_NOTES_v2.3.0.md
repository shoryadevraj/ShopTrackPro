# ShopTrack Pro v2.3.0

## Fixes and improvements

- Status notifications now dismiss automatically instead of remaining visible until the app restarts.
- Product category entry now offers suggestions from categories already present in the catalog.
- Scanning from a product detail page assigns the barcode to that product instead of opening the new-product flow.
- Public browsing mode now supports barcode scanning to search products in the selected shop.
- Product search now includes company/brand names.
- Added product duplication. Catalog details and price options are copied; barcode and stock are intentionally not copied.
- Added quick measurement presets for kg, g, L, ml, Piece, Packet, Bag, and Dozen, while keeping custom units editable.
- Updated application version to 2.3.0 (version code 28).

## Validation

This is a source update. It has not been compiled or tested on a physical Android device in this environment. Build the project and test all workflows before distributing the APK or using it for live business records.
